## 4. Método de búsqueda y selección

### 4.1 Fuentes de búsqueda

- Bases bibliográficas académicas.
- Repositorios institucionales del Distrito, AMVA/SIATA, IDEAM y entidades de gestión del riesgo.
- Repositorios de datos y código asociados con publicaciones.
- Hemeroteca únicamente como fuente complementaria para localizar o triangular eventos.

### 4.2 Cadenas de búsqueda

Registrar para cada búsqueda:

- Fecha.
- Base o repositorio.
- Cadena exacta.
- Filtros aplicados.
- Número de resultados revisados.
- Documentos incluidos y motivo.
- Documentos excluidos y motivo.

### 4.3 Criterios de inclusión

- Publicaciones entre 2022 y 2026, salvo excepciones justificadas.
- Cobertura directa de Medellín o el Valle de Aburrá, o pertinencia regional claramente explicada.
- Método, periodo, escala y fuentes de datos identificables.
- Aporte concreto a una pregunta, un producto o una afirmación del apartado.
- Preferencia por fuentes oficiales y publicaciones arbitradas.

### 4.4 Criterios de exclusión

- Documentos sin trazabilidad metodológica suficiente.
- Duplicados o versiones preliminares cuando exista versión final.
- Productos cuya resolución no permita la interpretación territorial pretendida.
- Noticias sin confirmación independiente cuando se usen para cuantificar eventos.

### 4.5 Jerarquía de evidencia

1. Datos y cartografía oficial local.
2. Observación instrumental local y publicaciones arbitradas con datos locales.
3. Fuentes oficiales nacionales y regionales.
4. Productos globales validados para la región.
5. Literatura contextual.
6. Hemeroteca como complemento y nunca como única prueba de un evento.
