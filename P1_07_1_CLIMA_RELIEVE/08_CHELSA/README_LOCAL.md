# CHELSA local

Este es el flujo de ejecución local. Copiar desde Drive la carpeta `08_CHELSA/02_DATOS` (subcarpetas `pr` y `tas`) a esta ubicación. El notebook `05_ENSO_CHELSA_plot.ipynb` detecta automáticamente esta carpeta y no monta Drive.

La copia maestra de código queda en el proyecto local. Las figuras se guardan en `08_CHELSA/04_PREVISUALIZACIONES`. No se combinan rutas de Colab con rutas locales.

La carpeta local todavía no contiene los 984 GeoTIFF: la descarga anterior se completó en Drive. Hasta copiar esos archivos, el plot no puede ejecutarse localmente.
